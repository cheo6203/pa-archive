# 대통령기록관 해외수집기록물 온라인 아카이브

대통령기록관이 발간한 『역대 대통령 해외수집기록물』 목록집·해제집을 구조화하여, 계층 탐색·검색·원문 열람·데이터 내려받기를 지원하는 단일 파일 웹 아카이브입니다.

## 수록 자료집

| 자료집 | 내용 | 항목 수 |
|--------|------|--------:|
| 미국편1 | 존슨·카터·레이건 대통령도서관 수집기록물 목록·설명·안내·소개 | 971 |
| 유럽편1 | 영국 국가기록원(TNA)·프랑스 외무부 기록관 수집기록물 | 382 |
| 미국편(지미카터) | 지미 카터 대통령 도서관 수집기록물 해제 (4단계 계층) | 234 |

| 미국편3(조지 부시) | 부시 대통령도서관 수집기록물 목록·총론·부록 1~8 | 333 |

| 프랑스편2(외무부기록관) | 프랑스 외무부기록관 수집기록물 목록 (부록 2종, OCR 기반) | 555 |

## 구성

```
index.html                  # 단일 파일 웹 아카이브 (로컬에서 바로 실행, 원문 이미지 내장)
modular/                    # 모듈 분리판 (웹서버·GitHub Pages 배포용)
  ├─ index.html
  ├─ style.css
  ├─ data.js
  └─ app.js
api/collections.json        # 자료집 메타 목록
api/<자료집>.json           # 자료집별 전체 항목·구조 데이터
data/<자료집>.csv           # 자료집별 서지정보 CSV (UTF-8 BOM)
```

## 두 가지 배포 방식

- **단일 파일(`index.html`)**: 파일 하나만 있으면 되고, 브라우저로 더블클릭해 바로 열 수 있습니다. 서버가 필요 없습니다.
- **모듈 분리판(`modular/`)**: 스타일·데이터·로직이 `style.css` / `data.js` / `app.js`로 분리되어 유지보수에 유리합니다. 단, 브라우저 보안정책(CORS)상 **웹서버 또는 GitHub Pages에서만** 동작합니다(로컬 더블클릭 불가).

## 웹에서 보기

`index.html` 을 브라우저로 열면 바로 사용할 수 있습니다.
GitHub Pages로 배포하면 온라인에서 접근할 수 있습니다.

## API (정적 JSON)

GitHub Pages 등으로 배포한 뒤 아래처럼 데이터를 가져올 수 있습니다.

```javascript
const BASE = 'https://<YOUR_GH_PAGES>';

// 자료집 목록
fetch(`${BASE}/api/collections.json`).then(r => r.json());

// 특정 자료집 전체 항목
fetch(`${BASE}/api/carter_haeje.json`)
  .then(r => r.json())
  .then(data => console.log(data.items.length));
```

## 데이터 정제 원칙

- 원본 자료집의 목차 구조(계층·부록·섹션)를 그대로 보존
- 원본에 없는 값은 채우지 않고 비워 둠 (임의 추정·생성 금지)
- 인쇄 페이지번호, 상호참조 각주 마커, 각주 인용 라인 등 비본문 요소 제거
- 깨진 특수문자(PUA) 복원·정리
